Super Res API

TWC super-resolution point forecast, read live through the proxy

A live probe of the TWC super-resolution point API (megapoints-conus), read through this app's server-side proxy so the API key never reaches the browser. It is a test harness for the data, not a product surface: it submits one coordinate and prints what came back.

Three constraints show up in every result. The model is tied to the HRRR domain, so coverage is the contiguous US only. Output is hourly. And one run reaches only as far as the timesteps it carries, so the horizon printed with each result is the real limit, whatever number of hours you ask for.

Point request

Paste a "lat, lon" pair into either coordinate box and it splits into both fields in that order. Hours back asks for times before now, which is where negative lead hours come from.
